# GTA di animali d'acqua ne ha sette in tutto, e sono questi:
#   a_c_fish        il pesce normale, ha TRE forme dentro
#   a_c_sharktiger  squalo tigre
#   a_c_sharkhammer squalo martello
#   a_c_stingray    razza
#   a_c_dolphin     delfino
#   a_c_killerwhale orca
#   a_c_humpback    megattera
# Gli ultimi tre sono enormi: appesi a una canna farebbero ridere,
# quindi non li usa nessuno. Se un giorno vuoi provarli, scrivi il
# nome qui accanto al pesce.

#   0 = affusolato, tipo trota   (trote, salmoni, lucci, siluri,
#                                 storioni, lepisostei, pesciolini)
#   1 = fusiforme, tipo tonnetto (tonni, sgombri, marlin, mare)
#   2 = alto e schiacciato, tipo persico (persici, boccaloni,
#                                 carpe, breme, panfish, ombrine)

# una scelta mia. Se ne vedi uno sbagliato, cambia il numero.
